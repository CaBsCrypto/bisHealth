# Prompts En Espanol Para La Landing De Trust Leaf

Este archivo reúne prompts generales, en español, para crear externamente la nueva landing de **Trust Leaf**.

Objetivo:
- mantener una dirección visual coherente;
- simplificar el mensaje;
- priorizar claridad, confianza y calidad visual;
- evitar que la landing se sienta técnica o confusa.

## Direccion General

Usa esta base como contexto al comienzo de cualquier prompt:

```text
Diseña una landing premium para Trust Leaf, una plataforma de cannabis medicinal que conecta pacientes, médicos y dispensarios en una sola experiencia confiable. El estilo debe sentirse elegante, claro, moderno, cálido y creíble. La prioridad es transmitir confianza, privacidad médica y simplicidad. Evitar visuales cripto, dashboards complejos, estética hacker, neon, exceso de cajas, exceso de texto o recursos típicos de Web3. Usar una dirección visual inspirada en salud premium: verdes profundos, marfil cálido, acentos suaves, mucho aire, buena jerarquía tipográfica y diseño fácil de entender en segundos.
```

## Prompt General Para Toda La Landing

```text
Diseña una landing completa para Trust Leaf, una plataforma de cannabis medicinal que ayuda a los pacientes a encontrar médicos aprobados, recibir recetas privadas validadas y acceder a dispensarios confiables. La landing debe ser minimalista, elegante, premium y muy fácil de entender. La narrativa principal debe estar centrada en el paciente y en la claridad del proceso. La estructura debe sentirse limpia, con pocas secciones, mucho aire visual, jerarquía clara y una estética de producto real. Evitar lenguaje técnico complejo y evitar que la tecnología sea el foco principal. La landing debe verse lista para jueces, grants, inversores y usuarios reales.
```

## Hero

```text
Diseña el hero principal de la landing de Trust Leaf. Debe comunicar en pocos segundos que el paciente puede encontrar médico, validar su receta y acceder a un dispensario confiable en una sola experiencia. El hero debe sentirse premium, limpio y muy claro. Incluir un mensaje central fuerte, una breve bajada y llamados a la acción simples. La visual debe verse como producto de salud moderno, no como plataforma técnica.
```

## Problema

```text
Diseña una sección que explique de forma muy simple el problema actual del cannabis medicinal: hoy el paciente debe navegar sistemas fragmentados para encontrar atención, gestionar su receta y acceder a tratamiento. La sección debe ser breve, elegante y fácil de leer. Mostrar el dolor del usuario sin sobrecargar la pantalla. El objetivo es que el visitante entienda rápidamente por qué hace falta una mejor experiencia.
```

## Como Funciona

```text
Diseña una sección de “cómo funciona” para Trust Leaf con una estructura muy clara y visual. El recorrido debe resumirse en pocos pasos: encontrar un médico aprobado, recibir una receta privada validada y ver dispensarios con inventario confiable. El diseño debe sentirse simple, didáctico y premium. Evitar explicaciones largas o detalles técnicos.
```

## Valor Para El Paciente

```text
Diseña una sección enfocada completamente en el valor para el paciente. El mensaje principal debe ser que Trust Leaf simplifica el acceso, protege la privacidad médica y genera confianza en el proceso completo. La sección debe sentirse cálida, aspiracional y moderna. Mostrar beneficios claros y fáciles de entender, sin sobreexplicar.
```

## Red Verificada

```text
Diseña una sección que muestre que Trust Leaf funciona sobre una red verificada de médicos y dispensarios aprobados. Esta parte debe transmitir legitimidad, confianza y curación de red. Visualmente debe verse como una red profesional premium, no como una consola técnica. Se pueden mostrar perfiles, tarjetas o directorios, pero de forma limpia y elegante.
```

## Privacidad Y Confianza

```text
Diseña una sección que comunique privacidad médica y confianza operativa de forma muy simple. El visitante debe entender que la información sensible del paciente se protege y que, al mismo tiempo, el sistema sigue siendo confiable y verificable. El tono debe ser calmado, premium y tranquilizador. Esta sección no debe sonar técnica ni legalista.
```

## Prueba De Infraestructura

```text
Diseña una sección breve que muestre que Trust Leaf no es solo una idea visual, sino un sistema conectado a infraestructura real. El objetivo no es explicar la tecnología en profundidad, sino transmitir credibilidad. Esta parte debe verse secundaria dentro de la landing: útil para dar confianza, pero sin competir con la historia principal del paciente.
```

## Cierre Y CTA Final

```text
Diseña la sección final de la landing de Trust Leaf con un cierre fuerte, simple y elegante. El mensaje debe reforzar que el paciente puede vivir una experiencia más clara, privada y confiable, mientras la red ya conecta atención, receta y acceso a dispensarios. Incluir llamados a la acción limpios y memorables. El cierre debe sentirse seguro, sofisticado y listo para presentación.
```

## Prompt Ultra Breve

Este prompt sirve si quieres pedir una versión mucho más abierta:

```text
Diseña una landing premium, minimalista y muy clara para Trust Leaf, una plataforma de cannabis medicinal centrada en el paciente. Debe transmitir confianza, privacidad médica, acceso simple a médicos aprobados y conexión con dispensarios confiables. Evitar estética técnica o cripto. Priorizar claridad, elegancia, aire visual y sensación de producto real.
```

## Recomendaciones De Uso

- Pide primero el `hero`, `como funciona` y `cta final`.
- Mantén la misma dirección visual en todas las secciones.
- Evita prompts demasiado largos o demasiado funcionales.
- Prioriza siempre: `claridad`, `confianza`, `premium`, `minimalismo`.
- Si una propuesta empieza a verse como dashboard o sitio técnico, corrígela hacia una experiencia de salud premium.
