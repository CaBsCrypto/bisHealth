# Testnet Readiness

Trust Leaf now has the right three core contracts for an MVP testnet release, and they are already deployed on Stellar testnet:

1. `trust_leaf_rbac`
2. `trust_leaf_traceability`
3. `trust_leaf_zk_medical`

These remain enough for the first public golden-path demo. Additional contracts may appear later, but they are optional support layers rather than blockers for the first testnet narrative.

## What is already done

- the three core contracts are deployed on testnet
- a live deployment manifest exists in `scripts/testnet/out/trustleaf-testnet-manifest.json`
- RBAC has been initialized
- baseline doctor / dispensary / lab / cultivator role addresses were granted
- the local frontend env can now be synced from the manifest
- the indexer has already ingested a live RBAC event from testnet

## What is not missing for MVP

- A separate treasury contract is not required yet. Fee bump sponsorship can stay off-chain in the backend for the first testnet cycle.
- A standalone payment contract is not required yet. DeFindex integration can begin as an API-backed checkout abstraction.
- A custom smart-account contract is not required yet. The wallet-less passkey layer can remain a staged integration while we validate the flow.

## What still blocks a fuller live demo

- Wiring the Vercel-hosted frontend env to the live contract ids instead of relying only on the local manifest bridge.
- Replacing more mock app state with data generated by live traceability and ZK contract interactions.
- Running one end-to-end happy path:
  - doctor issues a prescription commitment,
  - cultivator publishes a batch,
  - patient generates a proof,
  - dispensary consumes it.
- Completing the DeFindex-backed dispensary checkout flow with live credentials.

## Operational path

The repository now includes `scripts/testnet/` as the operational bridge to testnet:

- build -> upload -> deploy
- write a deployment manifest
- initialize RBAC
- grant baseline roles
- sync local frontend/indexer env files from the live manifest

Relevant scripts:

- `Deploy-TrustLeafTestnet.ps1`
- `Initialize-TrustLeafTestnet.ps1`
